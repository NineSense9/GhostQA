工作方式

从浏览器到证据

  1. Real BrowserPlaywright 执行动作、保留页面截图与浏览器状态。
  2. State Graphstructural cluster + semantic variant 记录状态和转移。
  3. Exploration Policy根据 novelty、workflow progress 和 branch memory 选下一步。
  4. OracleJS / 结构 / 规格断言生成候选问题。
  5. Replay候选必须重新走得出来，才进入确认流程。
  6. ddmin把可复现路径缩到更短的执行序列。
  7. Evidence报告、状态图、截图、trace 和实验 manifest 一起留档。
